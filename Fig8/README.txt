Supplementary material: Contains the supplementary figures and materials. 
The folder “contour_plots” contains Supplementary Figures 1-4, along with the necessary inputs and R code (plot1.R, plot2.R, plot3.R, and plot4.R). 
The folder “Boundary_estimation” contains Supplementary Figures 5-8, along with the necessary inputs (in the folders “boundary_outputs” and “boundary_outputs_gam_fast”) and R code (plot_LC_boundary_1.r and plot_LC_boundary_2.r).
It also contains Supplementary Figure 9, the input file “entity_counts_supl”, and the R code (Suppl_Fig9.R).

Prerequisites:
R (version 4.3.3)
R Packages: readr, dplyr, stringr, purrr, ggplot2, tidyr, tibble, mgcv, Polychrome
